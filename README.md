Sekkah Train Reservation System

A Java console application that simulates a train booking system for passengers and administrators.
Passengers can sign up, log in, search for trips, book tickets, cancel them, and request refunds.
Admins can log in to add trains and schedule new trips.

The system is fully built using Object-Oriented Programming concepts such as inheritance, enums, arrays of objects, and encapsulation.
All data is stored in arrays and managed through the BookingManager backend.

Main Features

Passenger signup & login

Trip search and viewing

Ticket booking (Economy / Business)

Ticket cancellation & refund

Admin features: Add Train / Add Trip

Input validation for safe and clean data entry

Project Structure

All .java files are located in the Sekkaah folder.
This project was developed as part of CSC231 (Object-Oriented Programming) and demonstrates the use of classes, inheritance, UML design, and system integration.
